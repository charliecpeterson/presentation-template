# Reusable personal photos

Photos I tend to reuse across talks, kept here so I don't have to track them
down in old repos each time. Reference with `<img src="assets/personal/...">`.

| File                 | What                                  | Typical use            |
|----------------------|---------------------------------------|------------------------|
| `cat-padfoot.jpg`    | Black cat (Padfoot)                   | Closing / "Questions?" |
| `cat-orange.jpg`     | Ginger cat by the monitor             | Closing slide          |
| `cats-two.jpg`       | Two cats on the desk while I work     | Closing slide          |
| `hedgehog-quill.jpg` | Hedgehog (Quill)                      | Closing / aside        |
| `charlie.png`        | Me at a poster session                | About / title / bio    |

The closing slide in `template.qmd` shows `cat-orange.jpg` as the default —
swap it for any of these or remove it.
